# Persian AI Dubbing

پروژه آغازین اندروید برای برنامه «Persian AI Dubbing».

## وضعیت فعلی
- برنامه اندروید با صفحه فارسی اجرا می‌شود.
- امکان انتخاب فایل صوتی یا ویدئویی وجود دارد.
- دکمه «شروع دوبله» فعلاً نمایشی است؛ دوبله واقعی هنوز پیاده‌سازی نشده است.

## برای فعال‌سازی دوبله واقعی
باید یک سرویس امن سمت سرور برای تبدیل گفتار به متن، ترجمه و تولید صدای فارسی متصل شود. کلیدهای API را داخل برنامه اندروید یا مخزن عمومی GitHub قرار ندهید.

## ساخت APK
این پروژه با Android Gradle Plugin ساخته شده است. می‌توان آن را در Android Studio باز کرد و از مسیر Build > Build APK(s) خروجی گرفت.
